# SINEMAKU - Katalog Film CLI

## Deskripsi
Sinemaku dibangun sebagai aplikasi berbasis CLI (Command Line Interface) menggunakan Kotlin dengan paradigma Pemrograman Berorientasi Objek (OOP) untuk mengelola katalog berbagai jenis tayangan, menyimpan daftar tontonan (watchlist), serta mencatat rating dan ulasan secara terstruktur.
